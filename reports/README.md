# Research artifacts

Git contains selected protocols, compact summaries and verification audits. Raw recorder archives, downloaded candle/funding datasets, training seeds and checkpoints, full trade/equity traces, and operational account snapshots remain local.

Paths to those larger or operational artifacts in the documentation identify local research outputs. Reproduce a study using its documented command and required input files; the retained manifests and audits identify inputs by hash. Use a fresh output directory when rerunning to preserve checked-in manifests. A completed software check or historical study does not establish a profitable trading strategy.
